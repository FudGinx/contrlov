# Корінь розбрату — мобільний веб-прототип

Горизонтальний інтерфейс для телефона. 2–6 учасників, самостійні боти та багатокористувацькі кімнати. Українське казкове оформлення, намальований атлас інгредієнтів і персонажів.

## Швидкий запуск Windows

Потрібен Node.js 22.13 або новіший. Відкрийте START_GAME.cmd. На комп’ютері гра доступна за адресою http://localhost:4173. У вікні запуску також надрукована адреса для телефонів у тій самій Wi-Fi мережі. Не закривайте вікно сервера під час гри.

Для гри з різних мереж потрібне публічне розгортання сервера. Посилання localhost доступне лише на комп’ютері, де запущено сервер.

## Режими

- «Грати з ботами»: від одного до п’яти ботів; перший рецепт гравець обирає сам.
- «Створити кімнату»: друзі входять за посиланням або шестизначним кодом до початку партії; господар може додати ботів.
- Кожен бачить тільки свою руку. Місце гравця відновлюється на тому самому пристрої кнопкою «Продовжити».
- У локальному запуску кімнати зберігаються у SQLite в .local/rooms.sqlite. Після перезапуску сервера можна продовжити. Не передавайте цю базу разом із публічною збіркою.

## Реалізовані правила

5 карт на старті, +3 на початку свого ходу; ліміт руки 10. Одне базове додавання або новий рецепт замість нього. До трьох незавершених замовлень, одне активне зілля. Комбінації без загального ліміту, продовження лише за ефектами інгредієнтів або персонажа. Нові карти з добору доступні одразу. Дозволене продовження понад рецепт.

Саботаж по черзі після всієї комбінації, по одній карті від кожного суперника. Колір збігається з останнім інгредієнтом. Негатив додається до початкового позитиву. Білі карти безкоштовні у свій хід. Оберіг прибирає один негатив. Дистиляція вимикає свій інгредієнт, звільняє позицію й не вимикає пов’язаний саботаж.

Готове зілля: карти та ефекти + індивідуальна вартість рецепта, мінімум 0. Безкоштовний обрив раз за свій хід дає тільки результат карт; рецепт скидається. Три повні зілля запускають фінал і дають першому +5; іншим по останньому ходу. Найбільший рахунок перемагає, за рівності — спільна перемога.

## Тестові рішення цього білда

Підготовлено 24 види кольорових інгредієнтів по 3 копії, 12 оберегів і 5 дистиляцій; 36 замовлень довжиною 3–5 позицій; 6 персонажів із різними здібностями. Це початковий набір для перевірки механіки, його значення не є затвердженим балансом.

Обмін у цьому інтерфейсі — 1:1 з підтвердженням адресата; бот може прийняти або відхилити пропозицію. Дистиляція працює з інгредієнтами в позиціях рецепта. Поле, рух, засів і пастки відкладені. Миттєві ефекти заднім числом не відкочуються. Гравець натискає кнопку завершення захисту, щоб мати час застосувати білі карти перед автоматичною оцінкою повного рецепта.

## Розробка

- node --test test/*.test.mjs — перевірка механіки, ботів, приватності рук і одночасних серверних дій.
- node scripts/build.mjs — збирає єдиний Cloudflare Worker з інтерфейсом і вбудованим атласом.
- node scripts/dev.mjs — локальний HTTP-сервер зі SQLite, без npm-залежностей.

Для Sites підготовлено .openai/hosting.json з прив’язкою D1 DB та міграцію drizzle/0000_rooms.sql. Секрети місць гравців не потрапляють у публічний стан кімнати; сервер перевіряє право на кожну дію та версію кімнати.
